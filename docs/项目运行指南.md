## 📦 依赖安装

### 第一步：检查环境

#### 1. 检查 Java 版本
```bash
java -version
javac -version
```

输出应类似：
```
java version "1.8.0_xxx"
```

#### 2. 检查 Maven 版本
```bash
mvn -version
```

输出应类似：
```
Apache Maven 3.8.x
```

### 第二步：克隆或获取项目

#### 方式一：使用 Git 克隆
```bash
git clone <repository-url>
cd tlias-web-management
```

#### 方式二：直接使用现有项目
确保在项目目录：
```bash
cd d:\program\idea_java\web-project01\tlias-web-management
```

### 第三步：安装项目依赖

#### 使用 Maven 安装依赖
```bash
# 清理并安装依赖（跳过测试）
mvn clean install -DskipTests

# 或者只编译
mvn clean compile -DskipTests
```

#### 验证依赖安装
```bash
mvn dependency:tree
```

## 🗄️ 数据库配置

### 第一步：创建数据库

#### 1. 登录 MySQL
```bash
mysql -u root -p
```

#### 2. 创建数据库
```sql
CREATE DATABASE tlias CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 3. 查看数据库
```sql
SHOW DATABASES;
```

### 第二步：导入数据库表结构

#### 查找 SQL 脚本
```bash
# 查看项目中是否有 SQL 脚本
dir src/main/resources/db/
# 或者
ls src/main/resources/db/
```

#### 导入脚本（如果有）
```bash
mysql -u root -p tlias < path/to/your/schema.sql
```

### 第三步：配置数据库连接

#### 查看配置文件
```yaml
# application.yml 或 application-dev.yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/tlias?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: 1234  # 改为您的密码
```

#### 修改数据库密码
根据您的实际 MySQL 密码修改配置文件中的 `password`。

## 🔧 中间件配置

### 一、Redis 配置

#### 1. 确保 Redis 已安装并启动

##### Windows 本地开发
```bash
# 启动 Redis 服务（如果已安装）
redis-server
```

##### Ubuntu 虚拟机（推荐）
按照 `ubuntu-redis-rabbitmq-setup.md` 中的步骤安装配置。

#### 2. 测试 Redis 连接
```bash
# 本地测试
redis-cli -a 123456 ping

# Windows PowerShell 测试连通性
Test-NetConnection -ComputerName 192.168.88.129 -Port 6379
```

#### 3. 修改 Redis 配置
```yaml
# application-vm.yml
spring:
  redis:
    host: 192.168.88.129  # 或 localhost
    port: 6379
    password: 123456
    database: 0
    timeout: 10000ms
```

---

### 二、RabbitMQ 配置

#### 1. 确保 RabbitMQ 已安装并启动

##### Ubuntu 虚拟机（推荐）
按照 `ubuntu-redis-rabbitmq-setup.md` 中的步骤安装配置。

#### 2. 测试 RabbitMQ 连接
```bash
# Windows PowerShell 测试连通性
Test-NetConnection -ComputerName 192.168.88.129 -Port 5672

# 访问管理界面
# http://192.168.88.129:15672
# 用户名: admin
# 密码: 123456
```

#### 3. 修改 RabbitMQ 配置
```yaml
# application-vm.yml
spring:
  rabbitmq:
    host: 192.168.88.129
    port: 5672
    username: admin
    password: 123456
    virtual-host: /
```

## 🚀 项目启动

### 第一步：选择运行环境

#### 修改激活的 Profile
```yaml
# application.yml
spring:
  profiles:
    active: vm  # 可选值: vm, dev, local
```

| Profile | 说明 |
|---------|------|
| `vm` | 虚拟机环境（使用 192.168.88.129） |
| `dev` | 开发环境（localhost） |
| `local` | 本地环境 |

### 第二步：启动项目

#### 方式一：使用 Maven 命令启动
```bash
cd d:\program\idea_java\web-project01\tlias-web-management
mvn spring-boot:run
```

#### 方式二：在 IDE 中启动
1. 打开项目：`d:\program\idea_java\web-project01\tlias-web-management`
2. 找到主类：`TliasWebManagementApplication.java`
3. 右键 → Run 'TliasWebManagementApplication'

#### 方式三：使用 JAR 包启动
```bash
# 先打包
mvn clean package -DskipTests

# 运行 JAR 包
java -jar target/tlias-web-management-0.0.1-SNAPSHOT.jar
```

### 第三步：查看启动日志

#### 成功启动标志
看到类似日志表示启动成功：
```
Started TliasWebManagementApplication in X.XXX seconds
```

#### 验证端口占用
```bash
# Windows
netstat -ano | findstr :8080

# Linux/Mac
netstat -tlnp | grep 8080
```

## 🐛 常见问题

### 问题 1：端口 8080 被占用

**错误信息：**
```
Web server failed to start. Port 8080 was already in use.
```

**解决方案：**
```yaml
# 修改 application.yml，更换端口
server:
  port: 8081  # 或其他可用端口
```

或停止占用端口的程序：
```bash
# Windows
netstat -ano | findstr :8080
taskkill /PID <进程ID> /F
```

---

### 问题 2：数据库连接失败

**错误信息：**
```
Access denied for user 'root'@'localhost'
```

**解决方案：**
1. 检查 MySQL 是否启动
2. 检查用户名密码是否正确
3. 检查数据库名称是否正确

---

### 问题 3：Redis 连接超时

**错误信息：**
```
Unable to connect to Redis
```

**解决方案：**
1. 检查 Redis 是否启动
2. 检查 IP 地址和端口是否正确
3. 检查防火墙是否开放 6379 端口
4. 检查 Redis 密码配置

---

### 问题 4：RabbitMQ 连接失败

**错误信息：**
```
java.net.ConnectException: Connection refused
```

**解决方案：**
1. 检查 RabbitMQ 是否启动
2. 检查 IP 地址和端口是否正确
3. 检查用户名密码是否正确
4. 访问 RabbitMQ 管理界面验证：http://192.168.88.129:15672

---

### 问题 5：Maven 依赖下载慢

**解决方案：**

配置 Maven 镜像（修改 `settings.xml`）：
```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <name>Aliyun Maven</name>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```
